ElevenLabs-ийн хэрэглээг шалгаж байна…

    

    
Энэ нь Railway-ийн нийтлэг ElevenLabs API key-тэй workspace-ийн багцад багтсан хэрэглээ; салбар тус бүрийн credit биш. Шинээр худалдаж авсан PAYG Top Up үлдэгдэл өөр тул ElevenLabs Developers → Top Up хэсэгт шалгана. Нэмэлт top-up-ийг энэ самбар автоматаар худалдаж авахгүй.

    
  



  
  
  
Монгол эмийн нэр зөв таних: ElevenLabs Agent → Security → Overrides хэсэгт System prompt болон ASR keywords-ийг зөвшөөрнө. Манай киоск яриа эхлэхэд зөвхөн энэ байгууллагын баталгаажуулсан каталогийн нэр, дуудлагын хувилбар, хязгаарласан Монгол prompt-ыг илгээдэг. Тохиргоо хаалттай бол browser-ийн хязгаарлагдсан дуут горим руу шилжинэ.

  
ElevenLabs API түлхүүр серверт нууц хэвээр байна. Хэрэглэгчийн яриаг идэвхжүүлэхийн өмнө эм зүйчийн аюулгүй байдлын баталгаажуулалт шаардлагатай. POS snapshot, эм зүйчийн webhook-ийн бодит холболтын төлөвийг “Холболт шалгах”-аар харна.


POS үнэ, үлдэгдлийн snapshot
Зөвхөн эм зүйчийн баталгаажуулсан каталогийн id таарсан бүтээгдэхүүний үнэ, үлдэгдлийг шинэчилнэ. Энэ нь live POS холболт биш.
📡 Киоск төхөөрөмжүүд
Дэлгэц бүрийг бүртгэж, онлайн/offline төлөвийг хянах боломжтой.
Төхөөрөмжийн нэг удаагийн холболтын түлхүүр
Энэ түлхүүрийг зөвхөн тухайн киоск дээр ашиглана. Буцааж сэргээж харуулахгүй.
Энэ нь одоогоор гараар татах backup юм. Серверээс автоматаар өөр газар хадгалах, сэргээх функц биш.

▤ Эмийн каталог
Салбарын хэрэглэгчид зөвхөн verified: true бүртгэлтэй эмийг харна. Нэрийн дуудлагын хувилбарыг aliases талбарт, зурагны HTTPS холбоосыг imageUrl талбарт оруулна. priceMnt, stock, description, warnings мэдээллийг эм зүйч баталгаажуулна.
Анхаар: verified=true бол эх сурвалж HTTPS холбоос, баталгаажуулсан огноо заавал бөглөнө. Энэ нь эм зүйчийн хяналтыг орлохгүй. POS холболтгүй үед үлдэгдэл автоматаар шинэчлэгдэхгүй.
CSV файл автоматаар verified=true болгохгүй. Импортын өмнө жагсаалтыг нягтлаарай.
